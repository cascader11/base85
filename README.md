# Base85 Cipher

Консольный шифровальщик для Linux.

## Использование

**Зашифровать:**
`./cipher e "ваш текст"`

**Расшифровать:**
`./cipher d "ваш шифр"`

## Важно
Длина текста должна быть кратна 4. 
Если символов меньше (например, 6), просто добавьте в конец пробелы до нужного количества (в данном случае 2 пробела). Без этого при расшифровке в конце появится мусор.
